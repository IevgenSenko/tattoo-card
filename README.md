# Ambrosia Tattoo

Статический сайт на HTML и CSS без сборки и зависимостей.

Сайт: https://ievgensenko.github.io/tattoo-card/
Instagram: https://www.instagram.com/ambrosia_tattoo/

Тексты и ссылки редактируются в `index.html`, оформление — в `style.css`.
`logo.jpg` — оригинальный логотип, предоставленный владельцем. Он отображается целиком без обрезки.
`work-1.jpg`, `work-2.jpg`, `work-3.jpg` — фотографии работ из Instagram, добавленные с разрешения владельца. Для замены загрузите новые фотографии с теми же именами либо измените пути в HTML; обновите также описания `alt`.

Источники фотографий:
- Цветочная композиция: https://www.instagram.com/ambrosia_tattoo/p/Dd-us-pIzSO/
- Коты, луна и звёзды: https://www.instagram.com/ambrosia_tattoo/p/Dd3j3COiB52/
- Цветок и надпись: https://www.instagram.com/ambrosia_tattoo/p/Ddlkd6bI-AG/

Все семь файлов находятся в корне репозитория. GitHub Pages публикует ветку `main`, папку `/(root)` и обновляет сайт после сохранения изменений.

Чтобы посмотреть сайт локально, откройте `index.html` в браузере.
